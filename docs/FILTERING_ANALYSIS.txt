GATK HAPLOTYPECALLER PARAMETERS
================================================================================

Their Parameters:
   --standard-min-confidence-threshold-for-calling 30
   --min-base-quality-score 20

Our Parameters:
   --standard-min-confidence-threshold-for-calling 30
   --min-base-quality-score 20

Result: IDENTICAL ✓

Note: These are CALLING thresholds (decide what gets called as a variant),
      NOT filtering thresholds (remove variants after calling).

Key Distinction:
   - Calling threshold: "Don't call a variant unless QUAL ≥ 30"
   - Filtering: "Call all variants, then remove those with QUAL < X"
   
Their pipeline uses calling thresholds only. No post-calling filters.

SNPEFF ANNOTATION
================================================================================

Their Command:
   snpEff -Xmx4g -c snpEff.config -v {database} {raw_vcf} > {annotated_vcf}

Our Command:
   java -Xmx8g -jar snpEff.jar ann -c snpEff.config -v NC_001477.1 \
        {raw_vcf} > {annotated_vcf}

Result: FUNCTIONALLY IDENTICAL ✓
   - Same tool (SnpEff)
   - Same database (NC_001477.1)
   - Same input (raw VCF from GATK)
   - Same output (annotated VCF)
   - Only difference: memory allocation (4g vs 8g, not relevant)

SnpEff DOES NOT FILTER variants. It only ANNOTATES them with:
   - Gene names
   - Variant effects (missense, synonymous, frameshift, etc.)
   - Impact levels (HIGH, MODERATE, LOW, MODIFIER)
   - Protein changes (HGVS notation)

All variants from GATK are preserved in the annotated VCF.

SNPSIFT EXTRACTFIELDS
================================================================================

Their Command:
   SnpSift extractFields {annotated_vcf} \
      CHROM POS REF ALT \
      "ANN[*].EFFECT" "ANN[*].IMPACT" "ANN[*].GENE" "ANN[*].GENEID" \
      "ANN[*].FEATURE" "ANN[*].HGVS_C" "ANN[*].HGVS_P" "ANN[*].AA_POS" \
      "EFF[*].CODON" "EFF[*].AA" "EFF[*].GENE" \
      > {snpsift_output}

What This Does:
   - Parses the ANN field from SnpEff VCF
   - Extracts specific annotation columns
   - Reformats into tab-separated table
   - NO FILTERING - all variants preserved

Our Approach:
   grep 'frameshift' {annotated_vcf} > {frameshifts_txt}

What This Does:
   - Searches for 'frameshift' in VCF lines
   - Extracts variants annotated as frameshifts by SnpEff
   - Same variants as SnpSift would extract
